#FUTURE_FS_03: Ethiopian International Hotel Web Application

A modern, responsive luxury hotel website inspired by Ethiopian hospitality, architecture, and culture.

The project focuses on creating a premium hotel booking experience using **React.js, JavaScript, Tailwind CSS v4, and React Router DOM**.

---

## ✨ Features

* 🏨 Luxury hotel homepage
* 🛏️ Rooms & Suites
* 🍽️ Dining & Restaurants
* 🧘 Facilities & Wellness
* 🎁 Special Offers
* 🖼️ Interactive Gallery
* 🇪🇹 Ethiopian-inspired luxury design
* 📖 Hotel story / About page
* 📍 Contact & location section
* 📅 Booking / reservation interface
* 🌓 Dark & Light mode
* 📱 Fully responsive design
* 🧩 Reusable React components
* 🗂️ Centralized hotel data
* 🔀 React Router navigation
* ✨ Smooth UI interactions
* 📱 Mobile navigation
* 🖼️ Gallery filtering and image preview
* ✅ Client-side form validation

## 🧩 Reusable Architecture

The project uses reusable components instead of duplicating UI.

Examples:

```text
Navbar
Footer
Hero
RoomCard
DiningCard
OfferCard
SectionTitle
Button
Reveal
```

Hotel information is also centralized in:

```text
src/data/data.js
```

This makes it easier to update rooms, offers, dining options, images, and hotel information without editing multiple components.
